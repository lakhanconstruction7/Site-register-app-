Need to set this up? (one-time, ~10 min)
  1. Go to Google Cloud Console and create a free project.
  2. Open APIs & Services → Library, search Google Drive API, click Enable.
  3. Go to APIs & Services → OAuth consent screen, choose External, fill the basic app info, and add your own Google account under Test users.
  4. Go to Credentials → Create Credentials → OAuth client ID, type Web application.
  5. Under Authorized JavaScript origins, add the exact web address this site is hosted at (e.g. https://yoursite.com).
  6. Copy the Client ID it gives you and paste it below.
